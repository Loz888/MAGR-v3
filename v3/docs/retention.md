# 首版数据保留策略

当前仅为单用户、单机工程环境。以下是保留与归档策略，不表示自动 GC 已实现。

- Trigger/Mailbox 与图 checkpoint：任务结束后保留至少 30 天；等待输入、审批或未知结果时不归档。
- Action、审批、预算、调用结果和引用关系：保留至少 90 天；未知结果未对账前不清理。
- 审计和验收证据：保留至少 180 天；失败证据不得被成功重试覆盖。
- Artifact：只允许基于引用清单与批准的归档计划清理；未关联的文件列入 inventory，当前不自动删除。
- Redis：限流键短 TTL，可重建，不承载长期记忆或业务权威。

首版已限制入口字节数、Artifact 大小、Mailbox 待消费数量、router inbox 容量、单调用输出、费用和调用次数。自动归档/GC 留待后续有独立验收的维护任务，禁止用 down -v 或破坏性清理代替。
