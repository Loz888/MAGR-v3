## 目标

让 Handoff 从固定 Commit 的仓库快照建立独立修复 Worktree；Live Repair 只在受限 R03 Docker 中执行测试。

## 执行要点

1. 严格验证仓库/Commit/文件内容 SHA；删除 Live Repair 对 `_fixture_files()`、`FIXED_DISPATCHER`、宿主 `pytest` 的依赖。
2. 测试命令只由可信 Go/Python Adapter 生成；容器禁网、只读根、无 Token、非 root、CPU/内存/PID/时间/输出上限、镜像 ID 锁定。
3. 区分 `baseline_not_reproduced`、`waiting_for_dependencies`、`build_failed`、`test_failed`、`timeout`、`sandbox_error`。
4. 无可信离线依赖包时返回 `waiting_for_dependencies`，不得访问 PyPI/npm/Go Proxy。
5. Workspace 与容器清理覆盖异常、取消、崩溃；遗留容器按 owner label 回收。
