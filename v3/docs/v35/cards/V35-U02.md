## 目标

把真实只读 Audit 产生的可验证 Finding 绑定 `evidence_id / source_uri / line_range / commit`，并在满足门禁时生成内容寻址 `RepairHandoff`。

## 执行要点

1. 区分 `suspected / reproduced / confirmed_static`；只有可复现失败回执或既定静态确认机制才能转 Handoff。
2. Handoff 固定仓库、Commit、目标、允许路径、预算、工具范围、审批状态、父 Run 与 Evidence Hash；不得从自然语言/Memory 扩权。
3. 改写 Workbench `auto_repair`：Live 模式不再使用固定 Dispatcher Finding；无 Handoff 时停在 `waiting_input`/`suspected`。
4. Handoff 序列化为内容寻址 Artifact 并绑定 Ledger；恢复时复用同一 Handoff。

## 负向测试

只有猜测没有证据、父 Run 未结束、不同 Commit、跨仓库来源、授权撤销、过期模型结果、越权 `allowed_paths`。

## 验收

- 真实只读 Audit 的 Finding 能建立合法 Handoff；不能复现或缺权限时明确停止。
