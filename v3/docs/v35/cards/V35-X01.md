# V35-X01：按需启用 R4 Experts，而非默认三专家

- 状态：TODO
- 依赖：V35-R05、V35-M02
- 优先级：P2
- 涉及文件：`routing/`、LangGraph 图、`repository_analysis/agent.py`、`workbench/orchestrator.py`（若已建立）、新 `tests/test_v35_x01.py`

## 目标

把多 Agent 从“默认并行三专家”改为“单主 Agent + 按需专家子图”；简单 Bug 不为形式调用专家。

## 执行要点

1. 路由基于证据的确定性判断（多文件/依赖/验证失败/安全问题/信息冲突/用户请求）。
2. 专家只作只读调查，输出结构化诊断/验证建议；写权限与最终决策归主 Agent。
3. 建立触发标准、预算硬上限、停止条件与去重；并行子任务由同一权威状态派生。
4. 超时、空结论、冲突、失败不得改写主 Agent 状态或绕过测试。

## 负向测试

单个 Go 小修复默认触发专家、专家无限循环/重复派发、专家失败后主流程被污染、专家尝试扩权。

## 验收

- 同一评测集比较单 Agent 与按需专家：成功率、成本、延迟、重复工作有数据；无收益时诚实说明。
- `tests/test_v35_x01.py` + 既有 routing/图测试。
