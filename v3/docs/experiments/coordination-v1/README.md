## 新失败与原三项失败

2. **F的4个初始任务未启动**：两个warm标签区组面对空primary列表仍输出两条deliver/null；检查拒绝后，八条依赖输入明确记录为阻断。两个cold标签区组各2/2，整体4/8。没有补考或修改模型输出。事后按请求哈希检查，四次F初始请求完全相同，却两次返回start、两次返回deliver/null；四次E首事件请求也相同，只有一次返回start。该描述性检查支持记录采样不稳定性，不能据此推断具体供应商缓存故障，且不改变原判分。见[重复请求与采样字段](request-repetition-analysis.json)。
