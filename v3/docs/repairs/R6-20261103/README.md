## 新版本冻结与实验解释

`eval/final-v3/cases.json` 在原三十题上新增明确的公开输出字段类型、请求能力和知识版本要求。业务题、行数据、公共 GitHub 代码与独立 Oracle 复用，因此这是已暴露题集的修复回归，不是新领域盲测；不能把改善全部解释为模型自身能力提高。版本冲突原负例同时缺少 SQL，真实案例本身存在混合条件；独立的版本判定检查另行隔离覆盖。

A 单 Agent、B 固定专家、C 按需专家都使用同一套新证据/契约/权限处理。安全拒绝和明确不足可能无需模型调用，必须与模型解题通过分别披露。修复补丁仍由真实模型生成并执行实际公开/隐藏 Go 测试；不存在运行时参考补丁或隐藏答案回传。
