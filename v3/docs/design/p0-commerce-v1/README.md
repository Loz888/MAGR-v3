## 产品介绍

研巡面向电商研发团队的值班开发和技术支持。用户提交订单收入异常后，系统关联业务口径、只读SQL结果和固定GitHub源码，输出有证据的调查结论；对许可范围内的Go纯函数缺陷，经沙箱测试和人工审批交付Draft PR。后续消息、证据变化和审批动作都保留在同一工单时间线。

第一版只覆盖重复支付、未支付/取消记录混入、整单退款状态排除三种已注册场景。业务成功限定为当前输入版本的调查契约通过，或获批Draft PR的远端对象核对完成。Draft PR不代表已合并或上线。
