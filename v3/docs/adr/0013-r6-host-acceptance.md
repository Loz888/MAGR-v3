# ADR 0013：R6 发布阻塞的实测范围

用户于2026-11-05明确要求关闭三项发布阻塞，随后选择建立独立Linux/systemd虚拟机。使用单独QEMU进程、独立内核/内存/块设备、PID1 systemd完成宿主部署与整节点强制断电恢复。主云容器和原V2/V3数据卷不作为故障注入对象。

私有PG/角色/CAS恢复包只恢复到无网卡的隔离副本，保留历史调用/费用；服务缺少模型和GitHub凭据，付费/外发关闭。新建测试状态与未知用量均明确标记controlled，不向供应商发送请求。

V2限定新增P7-06J，作为用户明确请求对ADR0001常规V2边界的单项例外。历史夹具在其审阅时刻检验检查点；正式Preflight仍使用当前时间并拒绝七天外或未来报价。不得改历史reviewed_at、重置原账或把离线门禁当真实模型业务通过。

实际结论仅适用于该虚拟机；不扩张为用户生产主机验收、物理磁盘掉电/云宿主丢失或多节点HA。报告必须保留这些边界、原始失败、内核/QEMU/部署文件哈希和逐次boot_id。
