# ADR 0007：R5 受限修复与逐步发布

状态：受控工程实现。R5 整体仍在进行；真实模型、真实 GitHub 源与 Draft PR 的组合验收为 NOT_RUN。

R1 live 已通过，用户明确要求继续 R5，因此实施隔离执行与审批工程。此前追加的 24 次调用授权绑定 R4 调查试验，剩余一次不转用于 R5。此次不新增付费调用或真实业务 PR。

## 权威与恢复

Engine 继续使用持有 advisory lock 的同一 PostgreSQL 会话记录业务状态。新增 migration 0010 保存冻结源码、步骤、候选、审批决策及三个发布子步骤。LangGraph 仅持有 Run 内的步骤状态，通过 interrupt 等待业务审批；恢复输入不能自行创建审批或 Outbox。网络、Docker、Go 测试和 CAS 写入均在业务事务之外。

每个补丁必须绑定基础 commit/tree、完整 diff、精确文件内容、公开及独立测试回执、内容哈希与到期时间。编辑意味着旧 Action 取消、输入版本增加并重新测试，不能复用旧审批。取消、旧 epoch、observer 和变化的输入不能开始下一项发布写入。已发出请求的晚到回执只记账，不恢复已取消的 Run。

Draft PR 是独立 action_type；评论 Dispatcher 默认只能领取 issue_comment。分支、提交、PR 分别在发送前保存请求哈希，发送后保存回执。任何不确定结果进入 outcome_unknown；重启不重新发送。只读核对必须同时匹配仓库、唯一分支、父 commit、整个目标 tree、文件 blob、完整正文、Draft 状态与 PR head/base。完整对象匹配才完成对账；只存在分支或提交时保留现场，不自动删除或续发。

## 当前约束

工程入口只支持 V3 自有的 Go 订单示例，明确标记 fixture_git；它是实际物化的独立 Git commit，不冒充 GitHub 源。模型接口接收公开源码与有限反馈，当前默认提供者是明确标记的受控补丁提供者。每个输入版本最多初始一次与两次修复，各版本共享同一 Run 的三分钟期限；编辑版本只验证用户补丁。隐藏测试使用独立 Python Oracle 生成，源码、预期值和日志不交给补丁提供者。

补丁只允许精确 unified diff、更改批准的源文件和一个纯函数体；拒绝模糊上下文、路径穿越、符号链接、测试/构建文件改动、imports、外部调用、并发与特殊 Go 指令。宿主上的可信 Go 辅助程序只解析 AST，不执行候选代码。

可信启动器只接受有界常规文件 tar，命令固定为 Go test。容器为非 root、断网、根文件系统只读、无凭据、无宿主挂载或 Docker socket、丢弃全部能力并禁止提权，限制 CPU/内存/PID/时间/输出。临时目录允许执行编译出的测试，禁止设备与 setuid。镜像 ID 和工具哈希锁定；超时或输出越界清除该 Run 的容器。启动及恢复只清理相同 Run 标签的遗留容器。

当前 Draft MCP Transport 只接受显式本地 stdio、无令牌的持久协议远端。工具名称及参数依据锁定官方 GitHub MCP v2.0.3 的真实 list_tools 核对；受控远端验证协议、部分成功和恢复。它不会创建真实 GitHub PR。R1/R4 许可、环境开关或审批 fixture Action 都不能打开生产写入。

## 后续 live 工作

需要实现并验收独立的 R5 source/model/write profile：固定真实 GitHub 基础提交、源码子目录与完整 tree 证明，将受控提供者替换为共享账本的真实模型适配器，并为一次 Draft PR 明确限定仓库、基础分支、调用次数、剩余累计费用和授权到期。真实代码测试、官方 MCP 返回结构与多步不确定写入必须单独验收，不能由当前协议成绩推定。

此交付映射原 P4/P5 的工作区、补丁约束、沙箱、审批与 Outbox 契约；不宣称原任务包所有卡完成，不移植 V2 固定补丁目录，不合并 PR，也不推进 R6。
