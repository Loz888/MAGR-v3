# ADR 0004：候选调用次数与总预算

日期：2026-11-02。依据：用户要求“候选配置准备为三次调用，上限us$2”。

将 config/live-r1-proposed.json 改为 max_model_calls=3、max_cost_micros=2000000，即最多 3 次调用合计 USD 2；保留原来源、模型、问题与一条审批结果评论的范围。

扩容次数纳入 profile 哈希，预检从配置读取上限。原有 1 次配置使用兼容哈希，不因新增默认字段而使历史授权失效。PG authorization_budgets 保存 call_limit；领取调用同时检查次数、已结算费用和未结算预占。不同 Run 共用同一 profile 的累计账本，结算和恢复不返还调用次数；未知调用仍占用次数和预算，不自动重发。

新增 0005 迁移，历史预算默认保留 1 次限制；原迁移与历史证据不改。新 profile 创建独立的绑定记录，不能用旧哈希授权扩充后的范围。

每个 Run 仍为有界单模型步骤；本次不增加模型循环、不修改审批规则、不启用付费开关、不发起真实调用。
