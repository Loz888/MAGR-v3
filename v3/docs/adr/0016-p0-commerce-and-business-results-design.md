# ADR 0016：电商工单与统一业务结果的P0设计

状态：DESIGN_COMPLETE，未实施。2026-11-06（Asia/Shanghai）。

用户指定只完成“完整电商工单闭环”和“统一业务结果判定”两项P0设计，其余改进停止。本ADR不将“设计完成”作为业务能力已交付的证明。

1. “研巡”采用已注册的合成电商场景、原知识/单表SQL/GitHub取证、原Go纯函数沙箱和Draft PR协议。业务Case关联原Thread及调查/修复Run，不另建执行调度权威。
2. 调查Run只读，结束后仅可在同Thread无活跃primary、来源与报告仍有效、独立修复许可匹配时创建修复Run。读取证据和公开报告不构成修改代码/创建PR的授权。
3. 业务结果作为Engine写入的不可变附加记录；执行状态继续来自app.runs，审批/交付来自原Action/Outbox。展示时以当前输入、授权和目标做投影，旧PASS不等于当前版本可交付。
4. 引用使用服务端实际来源目录、精确行区间及内容哈希；金额使用typed SQL cell与Decimal。独立判定检查公开业务规格，评测Oracle保持独立实现，隐藏答案不进入模型上下文。
5. 本次仅新增设计文档、JSON Schema与合成样例。新接口、表和检查器都是实施草案；不增加migration，不修改运行代码或旧实验，不新增付费或GitHub业务写入。
