# R6 修复回归 final-v3

本版本复用已暴露的 final-v1 三十项业务输入、GitHub 公共代码和独立 Oracle，新增明确的公开输出字段类型、请求能力和知识版本要求。final-v1 及 final-v2 的所有原始分数、输出和冻结文件保持原样。此版本是修复回归，不是新题盲测，不能据此宣称未知任务能力或与旧版本公平胜出。

数值来自实际 SQL 只读查询、SQL 聚合与独立运行时 Decimal 处理；运行时不导入 Oracle，也不读取 Case.rows 计算答案。缺失来源、版本冲突和撤销权限由真实来源元数据判断；请求能力由公开任务契约限定，不使用 negative_condition 或 case_id 决定状态。所有臂执行相同的安全检查；被确定性拒绝/证据不足的任务可为零模型调用，报告须披露。

输出数值为十进制字符串，布尔值为字符串 true/false；修复 values={} 且提供本地补丁；denied/insufficient 必须 values={}、diff=null。任何最终字段、数字或引用校验未通过都不返回 supported，重试受原每任务三次上限约束。原独立严格判定与质量门槛不变。
